# C++ の参照検索

このフォルダでは clangd の LSP が使えます(全 TU の索引は作成済み)。C++ の呼び出し元・参照・定義を探すときは、ソースを grep する前に、まず `lsp` ツールを使ってください。

- 呼び出し箇所・参照: 対象の宣言か定義の位置で `findReferences`。呼び出し元の関数: `incomingCalls`
- 宣言の位置は rg で探してから `lsp` に渡します。`workspaceSymbol` は、まだファイルを 1 つも開いていないうちは何も返しません(clangd はファイルを開いたときに索引を読み込みます)
- 解析は Debug|x64 の構成です。解析できなかったコードの参照は返りません
