# C++ 参照の検索(ltq)

このフォルダの C++ は、clang(libtooling)で全 TU を解析した参照索引があり、`ltq` コマンドで引けます。C++ の呼び出し箇所・参照・定義を探すときは、ソースを grep する前に、まず `ltq refs` を実行してください。

- `ltq refs <修飾名>`(例: `ltq refs a::io::File::Read`。末尾一致なので `File::Read` でもよい)は、1 回で次を返します
  - `calls`: clang が解決した呼び出し。どの関数の中に書かれているか(`[in ...]`)付き
  - `other references`: 関数ポインターの取得、テンプレート引数などの呼び出し以外の参照
  - `definitions and declarations`: 定義と宣言
  - `unresolved template calls (dep)`: テンプレート内で解決先が決まらない同名の呼び出し。注記(実体化での解決先)とソース行から、呼び出し先を自分で判断してください
  - `text matches ... not in the index`: ソースの同名の一致のうち、索引に無いものとその理由(コメント内・無効な `#if`・マクロ定義・文字列・解析されていないファイル)
- `calls` はそのまま答えに使えます。同じ名前を rg でソースから取り直して確かめる必要はありません。「コメント内」とされた一致は答えに含めません
- `ltq check <path:line> ...` は、その行が索引でどう扱われているか(参照・コメント内・無効な `#if` の中)を返します。rg などで見つけた行を答えに入れるか迷ったときに使います
- 実行できるシェルのコマンドは `ltq` だけです。パイプやリダイレクトは付けず、出力をそのまま読んでください
- 索引は Debug|x64 の解析結果です。解析にエラーがあった TU は、出力の先頭に出ます
